# Orbit Store 1.7.5 (Beta)

**LZ4 🦎 comes to Orbit**, alongside more games and improvements to downloads, TorBox and Library moves.

- **Find LZ4 games.** Select **LZ4** in the Format filter in Orbit Store’s browser, native PS5 app or Orbit Zero, in all four interfaces. The catalogue includes **49 LZ4 download options across 48 PS5 games**.
- **More games and download choices.** Orbit’s catalogue now contains **2,103 games: 1,132 PS5 and 971 PS4**, with **4,940 game download options**, plus **626 DLCs and add-ons with 628 options across 192 base games**.

We’re also shipping improvements and bug fixes across our apps:

## Orbit Store · Native PS5 app (FFPKG) and browser (ELF)

- **Better download recovery.** Interrupted connections retry from their saved position while other parts of the download continue. Resume checks the saved provider link and tells you when it needs refreshing. Brief service timeouts no longer immediately show Orbit as unavailable in the TV app.
- **Recognise your drive after a restart.** Orbit can recognise the original download drive after the PS5 remounts it following a power cut or repair, so you can resume from its retained partial file.
- **Clearer TorBox errors.** Downloads explain when the original source no longer has a file or the download server cannot be reached. Orbit respects provider cooldowns and uses at most eight connections per TorBox game.
- **More useful extraction progress.** Progress and speed update while large files extract, including files inside 7z archives.
- **Firmware information after extraction.** When supported game metadata provides a requirement, Orbit shows it in Downloads and before installation. Unknown requirements are not treated as a compatibility match.
- **Verified Library moves.** Orbit copies a game to the chosen drive, reads it back to check the copy, and registers the new location with ShadowMount before removing the original. If copying or registration fails, the original stays in place. A compatible ShadowMount version is required.
- **Check before downloading another copy.** If another format or version is already installed or on a drive, Orbit shows a warning and lets you choose **Download anyway**.

## Orbit Zero · Mac, Windows and Linux

- **Start Orbit through Payload Manager 0.6.3.** Fixed an upload and launch rejection when starting the PS5 service from Zero.
- **Downloads finish on exFAT drives.** Fixed a problem where a computer download could stop at 100% with an `EISDIR` error on drives that do not support hard links, including exFAT on Windows.
- **TorBox recovery.** Retryable connection failures can request a fresh temporary download link while keeping matching partial files. Downloads give clearer instructions for unreachable servers, cooldowns and files removed from the original source. If TorBox’s server stops accepting connections before any data arrives, Zero waits at least five minutes before retrying. TorBox uses at most eight connections per game.
- **Move games between PS5 drives.** Library includes destination selection, verification progress and cancellation before the original is removed, in all four interfaces. Connect to the matching PS5 service and keep both drives available.
- **Firmware details stay with the game.** Requirements found after extraction follow the game into Downloads and installation review.
- **A catalogue ready at startup.** Zero can use its bundled catalogue if the saved copy is missing or unreadable. A valid newer saved catalogue takes priority. Downloading still needs internet access.

## Install Orbit Zero on your computer

Choose the package matching your computer from **Assets**: macOS DMG, Windows installer or ZIP, or Ubuntu/Debian DEB. Linux TAR.GZ packages are also available. Both ARM64 and x64 builds are included; Linux DEB names use **amd64** for Intel/AMD computers. Quit the older app before installing the new version. See the [installation guide](https://github.com/saawant12/orbit-store-ps5/blob/main/guides/orbit-zero-installation.md) for setup and operating-system permissions.

## Install the native TV app (FFPKG)

Download `PPSA99177.ffpkg` from **Assets**, verify its `.sha256`, and copy it to `/data/homebrew/` on your PS5. Let ShadowMountPlus register it, then open **Orbit Store** from the Games row. Native app **1.11.2** includes the Orbit Store **1.7.5** service.

If an older Orbit service is running, select **App settings → Update / reinstall → Stop Orbit to restart** in its browser interface before opening the updated app so the new service can start. Pairing, settings and your queue remain saved. [Native installation and update guide](https://github.com/saawant12/orbit-store-ps5/blob/main/guides/getting-started.md#update-the-tv-app).

## Use or update the browser version (ELF)

Download `orbit_store.elf` and its `.sha256` from **Assets**, verify the checksum, then run the ELF through Payload Manager or your ELF loader. Open the Orbit shortcut in the Media tab, or `http://<ps5-ip>:34177/` on another device on the same local network.

To replace a running older version, select **App settings → Update / reinstall → Stop Orbit to restart**, then launch the new ELF. Orbit Zero also includes the matching ELF under **Console → Start Orbit on PS5**, so you can upload it from your computer without downloading the ELF separately.

On Orbit 1.5.0 or later, **Update Orbit** updates the TV app and the service together. Keep your local ELF loader running on port 9021 for automatic service restart; follow Orbit's manual instructions if it is unavailable. Reopen the TV app after updating it.

## Downloads and source

- `orbit_store.elf` is the PS5 service and browser interface; `PPSA99177.ffpkg` is the native TV app with the same service included.
- `Orbit-Zero-1.7.5-*` files are the desktop packages. Choose the operating system and architecture matching your computer.
- `orbit-store-1.7.5-source-bundle.zip` contains the corresponding Store application and dependency sources, licence notices and rebuild instructions.
- `SHA256SUMS` covers the release assets. Verify a binary with `shasum -a 256 -c <filename>.sha256`, or use `SHA256SUMS` for the desktop packages.
