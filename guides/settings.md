# Settings

Open **App settings** in Orbit Store’s default Store layout, or **Settings** in Crossbar, Cinema and Panorama. Orbit Zero has a **Settings** entry in all four layouts. Its Downloads gear opens Downloads settings directly; Back returns to Downloads.

## Where to find each control

| Category | Controls |
| --- | --- |
| Downloads | Simultaneous downloads, connections per download, automatic retries and PS5 shutdown. Zero also chooses the computer/PS5 download route here. |
| Storage & cleanup | Default PS5 drive, available space, archive/package cleanup and what happens to files when clearing history. Zero has its download folder and computer cache controls here. |
| Sources & accounts | Orbit Store’s enabled sources, plus Archive.org, Vikingfile and TorBox account controls supported by each app. |
| Devices | Pairing, connection details and Orbit Zero companion controls. Zero’s Console page keeps a connection overview and links here. |
| Appearance | Interface, language, motion and the selected layout’s appearance options. |
| Notifications | PS5 and ntfy notification preferences in Orbit Store. |
| Game catalogue | Catalogue version and refresh. |
| Updates & startup | Updates and restart/startup controls available in that app. Native links to the browser for payload-manager and auto-start setup. |
| Diagnostics & about | Version information and diagnostic/log export. |
| Support Orbit | Optional support links and QR codes. |

The categories are consistent across layouts; each app shows the controls it supports. Existing saved choices are retained.

## Computer or PS5?

In Zero, **This computer** labels computer downloads, account sessions, retry preferences, the download folder and cache cleanup. **On this PS5** labels the connected console’s shutdown controls. PS5 storage information describes drives connected to the console, not your computer.

Changing Zero’s connections or accounts does not change the PS5 service’s settings. Use Orbit Store to configure direct PS5 downloads.

## Automatic PS5 shutdown

Open **Downloads → Automatic PS5 shutdown**. Enable it and choose **All downloads** or one download under **Wait for**. The same selector is available in native Orbit, the browser and Zero. You can also choose **Shut down when finished** on a PS5 download and confirm. Orbit shows **Automatic shutdown scheduled.**; the same item then offers **Cancel automatic shutdown**.

Choosing a download sets the job to wait for; it does not allow Orbit to turn off the PS5 while other work remains. Downloads, transfers, installations and active file operations must finish. Paused or failed work, pending installation checks and a disconnected busy Zero computer keep shutdown blocked. Installation failure cancels the schedule.

When the console is ready, a **60-second countdown** appears. Cancel it from any connected Orbit app. Shutdown is off by default, and completed history does not trigger it after restarting Orbit.

## Language

Choose **Appearance → Language**. Orbit supports 26 interface languages, including Arabic with a mirrored layout and Japanese, Chinese and Korean fonts. Follow the system language or choose one for this device. Game names and provider pages may use their own language.
