# Find, download and install DLC

**Available in 1.5.0 and later.** Keep the Orbit app you use and its running PS5 service on the [same release](getting-started.md#which-files-to-download). The native FFPKG includes that service; Zero can upload its included copy. Refreshing the catalogue alone does not add the Add-ons page to older apps.

The catalogue has **626 add-ons for 192 games**, with **628 download options**. These are counted separately from base games.

## Find add-ons

Open **Add-ons**, after **Browse** in navigation, or choose **Add-ons (count)** on a game's details page to see its extras. The page works in the browser, native app and Orbit Zero, in Store, Crossbar, Cinema and Panorama.

Search by the DLC name or base-game name. Filter by **Platform**, **Type**, **Source** and **Region**; **Recently added** is the default order. Enabled source settings also apply to add-ons.

Each tile identifies the add-on, its base game and its type. When separate DLC artwork is unavailable, Orbit uses the base game's artwork.

## Understand the type

| Type | What it provides |
| --- | --- |
| **Expansion** | A campaign or substantial extra content. |
| **Content pack** | Extra items, characters, missions or other content. |
| **Activation package** | Unlocks content already present in the base game. It does not contain that content. |
| **Bundle** | Several add-ons or packages together. Check the details for known contents. |

## Check the required game

Before downloading, review the base-game edition, title ID, region and any known version requirements. PS4 and PS5 editions have their own add-ons. A matching title ID alone does not confirm compatibility.

If a requirement is unknown or Orbit cannot detect a matching base game, it explains that and still allows downloading. You can save the DLC for later, but should confirm the requirements before installing it. Orbit does not fetch missing game updates automatically.

Seeing a base game in Library does not mark its DLC as installed. Likewise, an add-on included in one edition or bundle is not necessarily included in another download option.

## Download now or send later

Open the add-on and choose a source, delivery method and destination in the usual download options. Archive.org sign-in, TorBox for supported sources, provider verification, archive passwords and download recovery work as they do for games.

Downloads identify both the base game and add-on, for example **Cuphead · The Delicious Last Course · DLC**. ZIP, RAR and 7z files extract on the selected PS5 drive, or on the computer before Zero transfers them.

In Zero, choose **This computer** to download without a connected PS5. Later, connect your console and choose **Send to PS5**. See the [Zero guide](orbit-zero.md).

## Install the selected add-on

After the files reach your PS5, open the completed entry in **Downloads** and choose **Downloaded files** or **Install on PS5**. Review the base-game requirements again, select the package and choose **Install on PS5**.

For a bundle, choose each package you intend to install. Orbit does not automatically install the whole bundle or select an installation order. Downloaded packages are kept by default. The optional **App settings → Storage & cleanup → Installed packages** setting can delete each package after successful installation; see [installation settings](install-games.md). Installing does not change firmware or jailbreak compatibility.

Downloading, transferring and installing have separate progress. See [installing downloaded games](install-games.md) for installation status, storage and recovery.

## If an add-on is missing

Check your enabled sources and clear the Add-ons filters. If you opened the page from a game's details, it is showing extras for that game; return to all add-ons to browse the full selection. Refresh the catalogue in settings to check for additions.

Older app versions continue receiving compatible base-game catalogues. Update the app and its matching PS5 service to use Add-ons in 1.5.0 or later. For a problem report, include the add-on, selected source and format, base-game title ID/version and exact error.
