# Orbit Store 1.9.0 (Beta)

> **🎉 Orbit is now on PS4 too.** Get the new [Orbit Store for PS4](https://github.com/saawant12/orbit-store-ps4) port, with downloads and setup instructions in its own repository.

We’re shipping new features and fixes across Orbit Store and Orbit Zero.

- **Scores and playtimes for 1,663 games.** See Metacritic scores and HowLongToBeat estimates on game pages. Browse by minimum score or playtime, choose Main Story, Main + Extras or Completionist, and save your filters. Coverage includes 645 scores and 1,568 playtime records; games with unknown values remain unlabelled. You can hide scores and playtimes on game cards in **Appearance**.
- **Remember your download choice.** Orbit remembers Direct or TorBox. Turn on **Always use TorBox** to use it for new downloads, subject to your account and the source’s support.
- **Improved Vikingfile downloads.** Better download-link detection and support for more Vikingfile servers help Orbit capture links more reliably across Orbit Store and Orbit Zero.
- **A clearer Library.** Games and Files stay together, with one counted **All games / Available now / Missing source** filter. Separate **Installed** and **Mounted** badges show each game’s status.
- **More catalogue detail.** Orbit now has **2,390 games with 5,335 download options**, plus **631 add-ons with 633 options across 197 base games**.
- **Artwork stays ready between visits.** Orbit keeps a bounded artwork cache across restarts, reuses cached backup images when a host is unavailable, and uses smaller images for tiles across the native app, browser and Zero.

## Orbit Store · Native PS5 app (FFPKG) and browser (ELF)

- **Check game folders before making repairs.** Orbit automatically checks extracted game folders. For an existing folder, open **Library → Files → Verify & Repair**. Review proposed changes before applying them. Orbit can restore required permissions and fix uniquely matched filename-capitalization errors; missing files remain warnings.
- **Find games inside nested folders.** After extraction or a transfer from Zero, Orbit sends the actual game folder to supported ShadowMount versions, even when it sits inside another folder. Existing completed downloads can use **Scan with ShadowMount** to try again without redownloading.
- **See the full connection address at startup.** The PS5 notification now includes its IP address and port alongside the pairing code.
- Scores, playtimes, download preferences and the updated Library are available in all four layouts.

## Orbit Zero · Mac, Windows and Linux

- **Connect other apps to Orbit Zero.** Enable the local REST API, then approve an app’s request or choose **Create API token** and copy the token into that app. Each app has its own access, which you can revoke at any time. Connected apps can browse the catalogue, start downloads, check progress and send a saved computer copy to your paired PS5.
- Scores, playtime filters, remembered Direct/TorBox choices and the updated Library match Orbit Store. Zero can also review and approve game-folder repairs on the paired PS5.

## Install Orbit Zero on your computer

Choose the package matching your computer from **Assets**: macOS DMG, Windows installer or ZIP, or Ubuntu/Debian DEB. Linux TAR.GZ packages are also available. Both ARM64 and x64 builds are included; Linux DEB names use **amd64** for Intel/AMD computers. Quit the older app before installing the new version. See the [installation guide](https://github.com/saawant12/orbit-store-ps5/blob/main/guides/orbit-zero-installation.md) for setup and operating-system permissions.

## Install the native TV app (FFPKG)

Download `PPSA99177.ffpkg` from **Assets**, verify its `.sha256`, and copy it to `/data/homebrew/` on your PS5. Let ShadowMountPlus register it, then open **Orbit Store** from the Games row. Native app **1.13.0** includes the matching Orbit Store **1.9.0** service.

If an older Orbit service is running, select **Stop Orbit to restart** in its browser interface before opening the updated app so the new service can start. Pairing, settings and your queue remain saved. This control is under **App settings → Updates & startup** in this release; older releases may call the section **Update / reinstall** or **Updates**. [Native installation and update guide](https://github.com/saawant12/orbit-store-ps5/blob/main/guides/getting-started.md#update-the-tv-app).

## Use or update the browser version (ELF)

Download `orbit_store.elf` and its `.sha256` from **Assets**, verify the checksum, then run the ELF through Payload Manager or your ELF loader. Open the Orbit shortcut in the Media tab, or `http://<ps5-ip>:34177/` on another device on the same local network.

To replace a running older version, select **Stop Orbit to restart**, then launch the new ELF. Orbit Zero also includes the matching ELF under **Console → Start Orbit on PS5**, so you can upload it from your computer without downloading the ELF separately.

On Orbit 1.5.0 or later, **Update Orbit** updates the TV app and the service together. In the native app from 1.8.2 on, select **Close and reopen** when asked; the reopened app starts its bundled service. Browser-only users can restart automatically with an active ELF loader on port 9021, or launch the updated ELF manually through their payload manager.

## Downloads and source

- **PS5:** `PPSA99177.ffpkg` includes the native TV app and download service. Use `orbit_store.elf` to run the service and browser interface on their own.
- **Mac, Windows and Linux:** choose the `Orbit-Zero-*` package for your operating system and processor.
- **Source code:** `orbit-store-1.9.0-source-bundle.zip` includes the Store source code, dependencies, licence notices and build instructions.
- **Checksums:** use `SHA256SUMS` to check your download, or run `shasum -a 256 -c <filename>.sha256` for the ELF or FFPKG.
